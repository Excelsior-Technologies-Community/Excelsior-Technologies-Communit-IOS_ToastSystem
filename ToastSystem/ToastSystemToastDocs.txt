Toast System – Short Guide
===========================

What it does
------------
- Shows small messages ("toasts") on top of your UI.
- Supports different types (success / error / warning / info), positions (top / center / bottom), duration, and optional haptic + sound.
- Can show multiple toasts in a queue.

Show a toast
------------
- Basic:

  `toast.show(.success, "Your message here")`

- With options:

  `toast.show(.warning, "Check your input", duration: 4.0, position: .center, haptic: true)`

Toast with action button
------------------------
`toast.show(.success, "Item added", duration: 4.0, action: { /* undo logic */ }, actionLabel: "Undo")`

Add a new button that uses it
-----------------------------
Example in a SwiftUI view:

`Button("My New Toast") { toast.show(.info, "Hello  new button") }`
